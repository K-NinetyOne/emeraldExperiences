Emerald Experiences travel website for Web Design and Client Side Scripting Module.

The basis of the project is to create an interactive webpage for a travel site that is responsive, has basic info on experiences and allows booking of experiences through a html form.

The project uses HTML, CSS and Javascript to fulfil this and other functionalities and features.

Responsiveness to different screen sizes was implemented via Flexbox. 
Form validation is carried out through the use of html tags with the exception of email matching which was conducted with a Javascript function attached to an eventListener on the submit button. 
Experience filters implemented using HTML classes and a Javascript filter function
